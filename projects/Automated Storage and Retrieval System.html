PROJECT CASE STUDY

Automated Storage and Retrieval System

Stepper Motors, 2020 Aluminum profile gantry structures, 3D printed end-effector body

A scaled-down Automated Shelf Storage System model designed to demonstrate the functionality and principles of a real-world Automated Storage and Retrieval System (ASRS). Featuring multi-axis gantry positioning, integrated storage compartments, and automated inventory tracking, this prototype serves as a functional proof-of-concept for modern warehouse automation. It illustrates key mechatronic concepts, including precise motion control, sensor feedback loops, and intelligent material handling workflows.

INTRODUCTION

Project Overview

This project presents a scaled-down Automated Shelf Storage System engineered to demonstrate the core operations and principles of a full-scale Automated Storage and Retrieval System (ASRS). Serving as a functional proof-of-concept for modern warehouse automation, the prototype integrates multi-axis gantry positioning, integrated storage compartments, and automated inventory tracking. By combining precise motion control, sensor feedback loops, and intelligent material handling workflows, the system highlights key mechatronic concepts applied to streamlined logistics and automated inventory management.

Horizontal translation

Horizontal translation along the X-axis is executed via a timing belt conveyor mechanism driven by a NEMA 17 frame bipolar stepper motor. The conveyor drive assembly is rigidly coupled to the primary ball screw platform, enabling synchronized linear displacement across the axis. To ensure structural stability and mitigate mechanical deflection under dynamic loading conditions, the moving assembly is bilaterally constrained using a dual stainless steel linear guide rod and rail system. This configuration reduces frictional torque, minimizes axial backlash, and ensures stable, high-precision positioning during high-speed motion sequences.

Vertical translation

Vertical translation along the Y-axis is actuated using a ball screw coupled to a NEMA 17 stepper motor. To resolve mechanical dimensional discrepancies between the motor output shaft and the ball screw interface, a custom extension assembly was implemented. This configuration incorporates a linear extension rod and a flexible coupling mechanism, ensuring precise rotational torque transmission and structural alignment between the motor driver and the ball screw assembly.

Operational Workflow for ASRS

To execute automated material handling across a 3x3 storage array, the gantry positioning mechanism coordinates multi-axis motion to align the end-effector with the target shelf coordinates(X,Y). Once planar alignment is achieved at the designated cell, the integrated forklift subsystem executes a controlled Z-axis prismatic translation sequence to perform cargo storage or retrieval. The storage cycle initiates as the forklift extends beneath the payload, elevates vertically to clear the shelf support, and retracts back into the main carriage; conversely, the retrieval cycle reverses this kinematic sequence to deposit cargo onto the material handling framework with high spatial repeatability.

End-effector Mechanism

To facilitate precise motion along the Z-axis, a custom additive-manufactured end-effector housing was designed to secure the actuator and couple the linear guide to the cargo handling framework. Actuation is provided by a 12 VDC unipolar stepper motor operating in conjunction with a linear guide mechanism to deliver controlled prismatic motion. This prismatic joint drives an acrylic platform along the vertical axis, enabling accurate spatial positioning of the end-effector during storage and retrieval sequences.
