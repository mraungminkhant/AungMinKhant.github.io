PROJECT CASE STUDY

Menki Noodle Vending Machine (Ladder Logic & HMI)

Cx Programming, Cx designer, Canva, Ladder Logic, HMI, Automation,

This is Menki, a fully simulated noodle vending machine built on Ladder Logic and HMI design. The inspiration came from YO-KAI EXPRESS, an AI-powered ramen vending machine that autonomously handles ordering, cooking, inventory management, and real-time sales analytics, all in roughly 90 seconds per bowl.

INTRODUCTION

Project Overview

Starting from scratch with only CX-Programmer for the Ladder Logic control sequence and CX-Designer for the HMI, both within the Omron Automation development environment where the entire machine had to be built purely through structured ladder logic and interface design. HMI graphics and display components were designed in Canva before being integrated into CX-Designer. This project is a simulation of a noodle vending machine that can autonomously handle ordering, cooking, and serving noodles, all within a short time frame.

Cx Programming and Ladder Logic

Cx Programming is a software development environment provided by Omron for programming and configuring their PLCs (Programmable Logic Controllers). It allows users to create ladder logic programs, which are graphical representations of control logic that resemble electrical relay logic diagrams. Ladder logic is widely used in industrial automation for controlling machinery and processes. Cx programming can also be used together with Cx designer, thus, it was utilized to create the HMI (Human-Machine Interface) for the Menki Noodle Vending Machine, allowing users to interact with the machine through a graphical interface, providing real-time feedback and control options.

Cx Designer and HMI software

Cx Designer is a software tool provided by Omron for designing and configuring Human-Machine Interfaces (HMIs). It allows users to create graphical interfaces that enable operators to interact with machines and processes. In the context of the Menki Noodle Vending Machine, Cx Designer was used to design the HMI, providing a user-friendly interface for customers to place orders, monitor the cooking process, and receive feedback on their selections. The HMI design was created in Canva and then integrated into Cx Designer for seamless operation.

Inspiration Behind the Project

Inspiration for the Menki Noodle Vending Machine project came from YO-KAI EXPRESS, an AI-powered ramen vending machine that autonomously handles ordering, cooking, inventory management, and real-time sales analytics, all in roughly 90 seconds per bowl. The goal was to create a similar autonomous noodle vending machine simulation using Ladder Logic and HMI design, showcasing the potential of automation in food service.

Screens for Ingredients

The screens for the ingredients are designed to provide users with a clear and intuitive interface for selecting their desired noodle ingredients. The HMI displays various options, allowing customers to learn about the ingredient of the order in detail which can be helpful in spotting in any allergies or health concerns. The interface is user-friendly, ensuring that even first-time users can easily navigate through the selection process. The screens also provide real-time feedback on the availability of ingredients, helping users make informed choices.

Restart Functions & Reordering

Customers can restart the vending process by the two available options on the HMI interface. This feature allows users to restart their order or order another, ensuring a flexible and user-friendly experience. The system is designed to safely reset to the default positions, preventing any potential malfunctions or misalignments during the restart process.

Buttons for Customers and Technicians

There are two buttons available for customers and technicians to interact with the Menki Noodle Vending Machine. The customer button allows users to retrieve their order, while the technician button is used restocking purposes. These buttons are strategically placed for easy access, ensuring that both customers and technicians can operate the machine efficiently and safely.

RESULTS

Final Results

Lastly, the final results of the Menki Noodle Vending Machine project demonstrate the successful simulation of all subsystems, achieving the intended functionality of autonomous noodle vending. The system operates seamlessly, with the HMI providing an intuitive interface for users to place orders and monitor the process. The mechanical components, including the rack-and-pinion assemblies and timing pulley gears, function as designed, ensuring precise movements of the acrylic flaps. The relay-based control system effectively manages the pneumatic cylinders, resulting in synchronized operations that enhance user safety and experience.
